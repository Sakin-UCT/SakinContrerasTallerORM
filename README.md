# Sistema de Reservas de Salas

## Descripción
Programa desarrollado en Python utilizando SQLAlchemy y SQLite.
Permite registrar salas, realizar reservas, consultar reservas y cancelar reservas.

## Funcionalidades
- Registrar salas.
- Consultar salas.
- Registrar reservas.
- Consultar reservas.
- Cancelar reservas.

## Ejecución del programa

1. Instalar las dependencias:
   pip install sqlalchemy

2. Crear las tablas:
   python crear_tabla.py

3. Ejecutar el programa:
   python main.py
